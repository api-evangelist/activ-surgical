# Activ Surgical

> Activ Surgical is a Boston, Massachusetts digital surgery company building intraoperative surgical intelligence. Its ActivSight Intelligent Light imaging module attaches to existing laparoscopic and robotic surgical systems and overlays augmented-reality physiology on a standard monitor — ActivPerfusion for dye-free real-time blood-perfusion imaging via laser speckle contrast imaging, and ActivICG for indocyanine green visualization. The module is powered by the hardware-agnostic ActivEdge computer-vision/AI platform.

Important for agents and integrators: **Activ Surgical publishes no public API, developer portal, SDK, CLI, MCP server, agent card, or machine-readable API contract.** As of 2026-08-02, no OpenAPI/Swagger/AsyncAPI/GraphQL surface was found on any probed host, and api./developer./developers./docs./status./trust.activsurgical.com do not resolve in DNS. Integration inquiries go through the contact form. Do not assume or synthesize an Activ Surgical API — none is published.
